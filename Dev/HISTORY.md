# Recovered history

The original Git metadata was unavailable when this repository was set up. The recovery reviewed 119 locally saved preview builds and kept their 82 distinct source checkpoints. The original 0.1 template also has its own initial commit and tag. The release tags from 0.2.0 to 0.4.16 point to the most recent recovered preview for each version.

Recovered checkpoints follow their build times. They include the QML game, source assets, the shared desktop runtime, and plugin files present in the corresponding preview. Compiled native code, save files, app settings, logs, and credentials are excluded. Older packages did not carry the native source, test suite, or development notes. The first regular project commit adds those from the current workspace. Some intermediate edits were never staged as preview builds and could not be recovered.
