# Blackbox issue ledger

Read this file and the latest entries in `~/.config/project-blackbox-issues.ini` at the start of every development pass. Add reports here as soon as they are observed, including informal reports, issues found during checks and ideas that need a decision. Keep the original wording or reproduction steps. Mark a fix verified only after the applicable checks below pass.

Run `python Desktop/checks.py` for the shared game and recovery checks. Failures are recorded in `$XDG_STATE_HOME/project-blackbox/regressions.jsonl`, or `~/.local/state/project-blackbox/regressions.jsonl` when that directory is unset. Blackbox's **Report a bug** button stores local notes and optional screenshots for the next development pass.

## Regression checklist

- [ ] Read incoming reports and list the affected features before editing. Record reproduction conditions and existing behavior, then link fixes and test results to the issue ID.
- [ ] Run the standalone Qt checks and compile QML. Check the affected feature through its normal entry point, including saved profiles and remapped input where relevant.
- [ ] Run the same Play scenario in the demo and the visible nested Plasma preview. Match wave, seed, difficulty, loadout, renderer, preset, size and frame limit where the host allows it. Exercise Ultra if the change affects art, lighting or HUD. Write down intentional host behavior separately.
- [ ] Exercise default and remapped input, menu focus, boundary positions and related actions. For desktop changes, verify the normal panel, application focus, clipboard, workspace changes and recovery in an isolated Plasma session.
- [ ] For pet or terminal changes, verify Pet admin off and on, mood reset, Ctrl+P on the wallpaper, both terminal locations, cancel and approve, and the requirement to press Enter for a shell draft. Check a normal KWin close against a disposable window in the nested session.
- [ ] Verify failures and repeat actions without modifying the base KDE profile. Record versions, results and any check still unverified.
